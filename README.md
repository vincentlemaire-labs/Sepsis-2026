This is the Github for the paper "Temporal Sepsis Modeling: a Fully Interpretable Relational Way"

This Github contains notebooks to reproduce the results.

These notbooks use the "API Core" of Khiops or the "API scikit-learn" for Khiops

The file requirements.txt contains the list of input used.

The two files : "S_PatientsWithFeatures_4logs_sep-tab.txt" and "S_PatientsWithLabels-sep-tab" are the data used in the paper.
